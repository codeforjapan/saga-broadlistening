# 質問の発話の上限を質問数に比例させ、話題ごとの発話予算をなくす

[AIインタビュー仕様アップデート](20261012_2200_AIインタビュー仕様アップデート.md) のターン制御のうち、上限と話題ごとの発話予算（`turn_budget`）を変更する。

## 背景

- 質問の発話の上限は 20 回で固定だった。質問が多い設定では1問あたりに使える発話が減る
- 話題ごとの発話予算（`turn_budget`）は、テンプレートでは 1〜4 を設定していたが、AIが提案した質問・手入力の質問には無く、既定の 3 回で次の話題へ移っていた。5問なら最大 15 回で、上限 20 に届く前に終わる
- `turn_budget` は職員には編集させておらず、設定項目としての価値が小さい。一方で、1つの話題に偏らせない役割はコードで持っておきたい

## 変更

| 項目 | 変更前 | 変更後 |
|---|---|---|
| 質問の発話の上限 | `QUESTION_TURN_LIMIT = 20`（固定） | 質問の数 × `QUESTION_TURNS_PER_TOPIC`（5）。`computeQuestionTurnLimit(topics)` で求め、`TurnState.questionTurnLimit` に持つ |
| 話題ごとの発話の上限 | 質問ごとの `turn_budget`（テンプレートで 1〜4、未設定は既定 3） | すべての質問で一律 `QUESTION_TURNS_PER_TOPIC`（5）。`topicTurnLimit(topic)` で求める（再開の話題だけ `RESUME_TURN_BUDGET` = 2） |
| `interview_questions.turn_budget` 列 | あり（既定 3、1〜4） | なし（`20261012100000_add_interview_purpose_design.sql` から削除。この列は develop・本番に未リリースのため、マイグレーションを直接直した） |
| 目的別テンプレートの `turn_budget` | 話題ごとに 1〜4 | なし |
| 対話プロンプトの話題一覧 | `[Q2｜発話4回まで] 質問` | `[Q2] 質問`（残りの回数は「いまの状況」節で伝える） |
| 関わり・言い足しの質問 | テンプレートで予算 1 にして深掘りさせない | 「聞き方の原則」で「最初の質問と、最後の言い足しの質問は深掘りしない」と指示する |

- 上限は事前定義の話題（設定した質問）だけで数え、再開の話題は数えない。質問が無い設定では上限 0 で、すぐに要約へ入る
- 「いまの状況」節の「上限○」は、その設定の上限を表示する
- 要約の段階から再開できるかの判定（質問の発話が残っているか）も、同じ上限で数える
- 話題ごとの上限（5）と1問あたりの上限（5）が同じなので、事前定義の話題を上限どおりに聞くだけなら全体の上限には届かない。全体の上限が実際に効くのは、要約から再開して話を続けたときになる。「残りの話題に最低1回ずつ回す」打ち切りも、同じ理由で通常は起きない
- テンプレート内で「場面は4回、影響は3回」のように話題ごとに差をつける設計は無くなる

## 注意

- 対話プロンプト（`interview-chat-system`）は、管理画面で公開した版があればそちらが優先される。「最後の言い足しの質問は深掘りしない」の指示を効かせるには、公開版を更新する
