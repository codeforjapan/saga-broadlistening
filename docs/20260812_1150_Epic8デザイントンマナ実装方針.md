## 4. #16 / #20 の重複ファイル担当割り（決定）

Epic本文が「着手前に決めよ」としている件。**「主体（誰が運営するか）は #16、語彙（何を扱うか）は #20」** で分担する。

| ファイル・領域 | 担当 | 理由 |
|---|---|---|
| `web/src/app/(main)/terms/page.tsx` | **#16** | 個人情報の取扱主体の差し替えが本質。文中の「法案」等の語彙も**同一PR内でまとめて**直し、#20 はこのファイルに触らない |
| `web/src/app/(main)/privacy/page.tsx`（`support@team-mir.ai` 含む） | **#16** | 同上 |
| `web/src/lib/prompt/source-code/templates/`（`shared-sections.ts` ほか） | **#16** | プロンプト内の政党説明と国政語彙は不可分 |
| 上記以外の画面文言（`top/about.tsx`、bills 系、進捗ステッパー等） | **#20** | 純粋な語彙の再定義 |

つまり **#16 が触ったファイルには #20 は触らない**（ファイル単位の排他）。#16 を Wave 0、#20 を Wave 2 に置くことで時間的にも分離する。
