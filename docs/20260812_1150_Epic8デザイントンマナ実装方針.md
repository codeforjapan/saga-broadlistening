- #17 はトークン値（#9）にのみ依存し `globals.css` を触らないため、実際には Wave 1 と同時に走らせてもよい。

### Waveをまたぐ依存の理由

- `globals.css` は #9/#10/#11/#12/#13 全てが触る。**#9 が `@theme inline` の構造（プリミティブ→セマンティックの2層）を確定させてから**他を載せないと全PRがコンフリクトする。
- #13/#14 は「新トークンが存在すること」が前提なので Wave 2。
- #18/#19 は検証フェーズであり全変更のマージ後でないと意味がない。

## 4. #16 / #20 の重複ファイル担当割り（決定）

Epic本文が「着手前に決めよ」としている件。**「主体（誰が運営するか）は #16、語彙（何を扱うか）は #20」** で分担する。

| ファイル・領域 | 担当 | 理由 |

| `web/src/app/(main)/terms/page.tsx` | **#16** | 個人情報の取扱主体の差し替えが本質。文中の「法案」等の語彙も**同一PR内でまとめて**直し、#20 はこのファイルに触らない |
