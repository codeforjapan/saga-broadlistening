# 国政語彙から施策語彙への対応表（#20）

> Epic #8 / Issue #20 ／ 作成日: 2026-08-26 ／ **佐賀市の確認待ち**

みらい議会（国政向け）由来の画面文言を、佐賀市の広聴基盤の語彙へ再定義した。

## 前提: 語彙の正は `20260813demo` ブランチ

当初は「法案 → 議案 / 国会 → 市議会」（市議会の審議語彙）で置換していたが、以下の理由で
**「法案・議案 → 施策 / 国会 → 佐賀市」** に統一し直した。

- 佐賀市向けデモの `20260813demo` ブランチが「施策」で通しており、これを正とする
- Epic #8 要求仕様5章も「法案 → 施策」「国会 → 佐賀市」と定めている
- Epic #54（#55）で DB のテーブル自体が `bills` → `policies`（施策）へ再定義済み。
  マイグレーションのコメントも「国政の『議案（bill）』を地方行政の『施策（policy）』へ
  再定義する」と明記しており、画面文言だけ「議案」に留めると DB と食い違う

## 対応表

| 変更前 | 変更後 | 備考 |
|---|---|---|
| 法案 | 施策 | web / admin / packages の表示文言・コメント・プロンプト・テストを一括置換 |
| 議案 | 施策 | fork 元から残っていた admin の「議案管理」等も含む |
| 国会議事堂（画像alt） | 市民参加をイメージした背景画像 | ヒーロー画像は Epic #8 で抽象イメージに差し替え済みで、alt だけが国会議事堂のまま残っていた |
| いま国会で議論されていること | いま佐賀市で検討されている施策を | トップのヒーローコピー |
| 国会に提出された注目法案 | 佐賀市が検討している注目施策 | 注目施策セクション |
| シェアして国会の議論をオープンに | シェアして佐賀市の施策をオープンに | シェアモーダル |
| 国会や法案についてAIに質問する | 佐賀市の施策についてAIに質問する | チャット導線（aria-label 含む） |
| 国会って何をするところ？ | 佐賀市はどんな施策を検討しているの？ | チャットのサンプル質問 |
| 国会で検討されている | 佐賀市で検討されている | インタビューLP |

| 国会提出法案等の関連テーマ | 佐賀市の施策等の関連テーマ | 利用規約 |
| 国会に提出された議案などの公開情報を基に…内閣提出法案（閣法）を対象 | 佐賀市が公開している情報を基に… | 施策詳細の免責文。閣法の限定は自治体では意味を持たないため削除 |
| 「国民全体」「全国民」 | 「市民全体」「全市民」 | インタビューシミュレーションのペルソナ生成プロンプト |

| 今回の法改正のうち | 今回の施策のうち | インタビューのデフォルト質問Q1 |
| 審議前・審議中などのステータス | 検討中・実施中などのステータス | サービス説明プロンプト。審議ステータスは Epic #54 で廃止済み |
| 施策の審議状況 | 施策の検討状況 | Web検索ルールのプロンプト |
| 施策の政策論から離れた | 施策の論点から離れた | 「施策の政策論」が同語反復になるため |
| あなたは日本の施策に関する… | あなたは佐賀市の施策に関する… | トピック統合プロンプト |
| 佐賀市の議案や政策をわかりやすく伝え… | 佐賀市の施策をわかりやすく伝え… | `web/public/manifest.json` の description（PWAインストールカード） |
| bills テーブル / bill_contents | policies テーブル / policy_contents | MCPツールの説明文。Epic #54 でテーブルが改名されており、AIエージェントに誤った表を案内していた |

`web/public/manifest.json` の description に国政由来の語彙が残らないことは
`packages/branding/src/brand-meta.test.ts` の回帰テストで担保している。

## Epic #54 のデータモデル再定義で不要になったもの

`feat/epic8` の取り込みにより、当初 Issue #20 で再設計対象としていた以下は**ファイルごと削除済み**で、
本PRでの対応が不要になった。

- 進捗ステッパー（`bill-status-progress.tsx`）と `bill-progress.ts` — 二院制の4段階そのものが消えた
- 審議ステータス（`bill_status_enum` / `bill-status.ts`）— `policies` の公開状態は `draft` / `published` の2値のみ
- 提出元区分（`house_enum` = 衆議院 / 参議院）— カラムごと廃止
- 国会会期（`diet_sessions` 一式・`/kokkai/[slug]/bills`・国会会期管理画面）— ドメインごと廃止
- 衆議院URL（`shugiin_url`）のラベル・placeholder — カラムごと廃止

そのため Issue #20 の「進捗ステッパーの再設計」「衆議院URLの再定義」は、
**#20 では対応不要（Epic #54 で解消済み）** と判断した。

## 対象外

Issue #20 のスコープ定義どおり、以下は変更していない。

- ディレクトリ名・ファイル名・型名（`features/bills/`, `Bill*`）— Epic #8 完了後のフォローアップ（`shared/types/index.ts` にコメントあり）
- URLパス（`/bills/[id]`）
- ワークスペースのパッケージ名（`@mirai-gikai/*`）
- 内部識別子（`supabase/config.toml` の `project_id`、`MCP_CLIENT_ID`）
- `supabase/migrations/` の SQL コメント（適用済みマイグレーションは書き換えない）
- `packages/seed/` の投入データ（国政のサンプル施策のまま）— #62「シードデータを新データモデルへ刷新する」で対応
- 「みらい議会」「チームみらい」等のブランド表記 — #15 / #16 の担当

## 佐賀市に確認したい項目

1. **「施策」で統一してよいか** — 条例・予算・計画・事業を包括する語として妥当か。
   「事業」「取組」等を使い分ける必要があるか
2. **主体の表記** — 画面文言では「佐賀市」に統一した。「市」「本市」等の表記ゆれの方針。
   あわせて、インタビューシミュレーションのプロンプトに残っている「政治家へ伝えたいメッセージ」の
   「政治家」を「市（行政）」「市議会議員」等に読み替えるべきか（フィールド名 `message_to_politicians` は識別子のため不変）
3. **市議会の議案を扱う場面が将来的にあるか** — ある場合は「施策」とは別の語彙・導線が必要
