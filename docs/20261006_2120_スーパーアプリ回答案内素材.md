# 市HP向け案内文案と確認事項

本資料はEpic #147の実装に合わせた案内文案です。入口の正式な位置、公開URL、市HPの説明ページURLはOPTiM・佐賀市の確認待ちです。

## 市HP掲載文案

チカットでは、佐賀市の施策やテーマについてAIがチャット形式でご意見を伺います。施策の紹介や公開された意見は、通常のブラウザからご覧いただけます。

佐賀市スーパーアプリから回答を受け付けるテーマでは、スーパーアプリを開き、チカットの画面で回答したいテーマを選んでください。内容を確認して同意すると、AIインタビューが始まります。途中で離れた場合は、同じアプリ・同じ利用環境から回答を再開できます。

スーパーアプリ内のチカットへの入口が確定したら、上記の「スーパーアプリを開き」の後に、正式な画面名とボタン名を追記してください。

## 通常ブラウザからの操作

1. チカットで施策やテーマを閲覧する。
2. 「アプリから回答する方法」の案内を読む。
3. 佐賀市スーパーアプリを手動で開く。
4. チカットで案内に表示されたテーマ名を選び直す。
5. 同意してAIインタビューに回答する。

ブラウザで選んだテーマは、スーパーアプリに自動では引き継がれません。市HPのリンクもアプリを直接起動するものではありません。

## URL

- 市HPからリンクするチカットの公開TOP URL：正式URLを確認して記入。
- スーパーアプリに登録する入口URL：正式URLに `#uid=<利用者UID>` を付ける方式。パラメータ名・形式は暫定。
- 市HPの説明ページURL：提供待ち。webの環境変数 `SAGA_SUPER_APP_GUIDE_URL` に設定。
- PRプレビューはレビュー用です。市HPの公開リンク先には使用しません。

## 画面素材

ローカルの検証用テーマで、通常ブラウザの案内表示とUID紐付け後の回答開始表示を撮影します。素材のラベルに「ローカル検証用」を付け、公開版や実機検証済みの画像とは区別します。実機での回答中画面は #146 で差し替えてください。

## OPTiM・佐賀市への確認事項

- `#uid=` のパラメータ名、UID形式・長さ・安定性、利用者切り替え時の挙動。
- フラグメント付きURLをWebViewがそのまま開けるか。
- WebView POSTなど、URL以外で受け渡す方式の可否。
- ミニアプリ／市民証画面のどちらを入口にするか、正式な画面・ボタン名。
- チカットの公開TOP URLとスーパーアプリに登録するURL。
- 市HPの案内ページURL。
- 検証用アプリとインストール手順の提供時期。

## #146の実機確認

iOS・Androidごとに端末、OS、アプリバージョン、再現手順を記録してください。

- UID受け取り、URLからの除去、Cookie付与、外部ID・ユーザー・回答のDB紐付け。
- 初回の匿名認証が遅い場合も、開き直さず回答ボタンへ切り替わること。
- アプリ再起動後のCookie保持と回答再開。
- Cookie消失後は外部IDの紐付けを再作成し、過去の会話を自動復元しないこと。
- 別利用者・別UIDから他人の会話を閲覧・変更できないこと。
- public／external_identityの導線と、直接アクセスしたページ・APIの参加判定。
- 同意、回答、完了、結果表示とストリーミング。
- ルビ、難易度切り替え、外部リンクの開き方。
- セーフエリア、画面高さ、キーボード表示時の入力欄。
- GAやLangfuseへUIDが含まれないこと。
