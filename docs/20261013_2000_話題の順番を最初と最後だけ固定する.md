# 話題の順番を最初と最後だけ固定し、移るときは前の答えとつなぐ

[AIインタビュー仕様アップデート](20261012_2200_AIインタビュー仕様アップデート.md) のうち、話題の順番と、次の話題へ移るときの言い方を変更する。

## 背景

- 話題は設定した順に聞く作りだったため、前の答えとつながらない質問でも次に来て、切り替わりが唐突だった
  - 例：「時間があったら、彼女さんと話したり、ふたりでご飯に行ったりしたい、ということですね。あと2つです。何かを後回しにしたな、と感じた経験はありますか？」
- 以前の設計（main ブランチの loop / bulk / targeted モード）は、質問を順番どおりに使わず「会話の流れに応じて選ぶ」「次の事前定義質問に自然に移行する」としていた。残りの問数にも触れなかった
- 「あと○つです」は前の話の受け止めの直後に事務的な一言が入り、切り替わりを強めていた

## 変更

| 項目 | 変更前 | 変更後 |
|---|---|---|
| 話題の順番 | 設定した順に聞く | 最初の話題から始め、最後の話題（言い足しの質問など）は最後に聞く。間の話題は、前の答えにいちばん自然につながるものをAIが選ぶ |
| 次に聞ける話題（コード） | すぐ次の1つ（`TurnState.next`） | 最後の話題を除く、まだ聞いていない話題すべて（`TurnState.candidates`）。最後の話題は、ほかを聞き終えると候補になる。`next` は候補の先頭で、AIが選ばなかったときの移り先 |
| 飛ばした話題 | 戻れない（いまの話題より後ろだけを残りとして数えた） | 後から聞ける（まだ聞いていない話題すべてが残り） |
| AIが返す question_id の読み替え | いまの話題か、すぐ次の話題だけ受け付ける | いまの話題か、次に聞ける話題のどれでも受け付ける。発話が0なのに選ばなかったら候補の先頭へ |
| 「いまの状況」節 | 次の話題を1つ、残りの話題を「Q3・Q4（あと2つ）」で示す | 次に聞ける話題を一覧で示し、最後に聞く話題を別に書く。まだ聞いていない話題の数は「回答者には伝えない」と添える |
| 前の答えを受ける質問 | （順番固定なので不要） | 「その」「それ」などで前の答えを指す質問は、受けている質問の後に聞く（プロンプトで指示） |
| 移るときの言い方 | 整理を1文、残り2つ以下で「あと○つです」 | 前の答えにつながる言葉があれば、それを前置きにして聞く（例をプロンプトに載せた）。なければ「では、話を変えて、△△について伺います」。前置きと語順は変えてよいが、何を聞くか・範囲の指定・答え方は変えない |
| 残りの数 | 残り2つ以下で「あと○つです」、短く答えてほしいとき「残りは○つです」 | 伝えない。最後の話題に移るときだけ「最後の質問です」 |

## 変えないもの

- 発話の上限（全体＝質問の数×5、話題ごと5）、要約への移行、再開（再開の話題の後に事前定義の話題は無い）
- 選択肢ボタンは、初めて聞く事前定義の質問に出す。言い回しを変えても答え方は変えないので、ボタンはそのまま使える
- 進捗バーは聞いた質問の数で計算しているので、順番が変わっても変わらない

## 注意

- 対話プロンプト（`interview-chat-system`）は、管理画面で公開した版があればそちらが優先される。公開版の「話題（この順に聞く）」「話題は上の順に聞く」「あと○つです」の記述は、この変更に合わせて更新する
- 「いまの状況」節と「出力」節はコードが毎ターン作るので、公開版のテンプレートに関係なく変わる
