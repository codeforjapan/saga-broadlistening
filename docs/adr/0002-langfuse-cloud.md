# ADR 0002: Langfuse Cloudの採用

## ステータス

提案中

## 日付

2026-07-14

## コンテキスト

Langfuse は LLM 呼び出しの観測・トレーシングに使う想定で、ECS 上でのセルフホストか、Langfuse Cloud 利用かが未確定だった（Supabase と同じ整理資料に記載）。

## 決定

Langfuse Cloud を採用する。セルフホストは行わない。

## 根拠

- 技術的考慮: セルフホスト運用の負荷軽減。
- コスト: PJ-1746 のサーバー費見積りとの整合。
- 時間的制約: 迅速な導入が可能。

## 影響

### メリット

- 運用負荷が低い
- 導入が速い
- コスト見積りと整合する

### 懸念点

- LLMのプロンプト・レスポンスなど機微情報がLangfuse Cloud側に送信される
  - 緩和策: 個人情報を含むログのマスキング方針を別途整備し、契約前にLangfuse社のデータ処理条件（データ保存地域・保持期間等）を確認する。

## 代替案

ECS 上へのセルフホスト。データを外部に出さないメリットがあるが、運用負荷とコスト増のため不採用。

## 今後の方向性

Langfuse社のデータ処理条件確認の結果、要件を満たさない場合はセルフホストを再検討する。
